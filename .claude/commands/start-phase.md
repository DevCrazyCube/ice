# Command: start-phase

## Purpose

Use this command when beginning a new development phase.

## Steps

1. **Read `docs/07-roadmap/current-phase.md`** — understand what phase is active and what is in scope
2. **Read `docs/07-roadmap/non-goals.md`** — confirm you know what to avoid
3. **Update `current-phase.md`** — change the phase name, in-scope items, and out-of-scope items
4. **Read the relevant skill docs** — if starting the agent phase, read `agent-runtime.md`; if starting the data phase, read `db-schema-design.md`
5. **Identify the first concrete deliverable** — do not attempt the entire phase in one go

## Checklist Before Writing Code

- [ ] `current-phase.md` has been updated
- [ ] Relevant skill docs have been read
- [ ] The first task is specific and small
- [ ] No out-of-scope work is included
- [ ] No new packages/frameworks introduced without justification

## Rule

Do not start coding a new phase without updating `current-phase.md` first.
